calcultor.py is a calculator that calculates the sum, difference, product, or quotient of two number using their respective operation (+,-,*,/)
it asks for the first number, then the operation, then the second number

exchange rates.py is a calculator that changes the currency of money from one to another
there are available currencies: USD, AED, EGP, SAR, JPY, EUR
you can convert any currency to any OTHER currency

numberguessing.py is a number guessing game, where the system chooses a random number from 1 to 1000
you have to guess that number using the hints 'greater' or 'lower', which are comparisons between the system number and your most recent number 
when you the correct number it will alert you that you won the game
